# Documentation Assets & Previews

This folder holds screenshots, GIFs, and media referenced in `README.md`:

- `dashboard_preview.png`: Full screenshot of `./audezeforlinux dashboard` (Hero image).
- `controls_preview.png`: Screenshot of Tab 1 (Controls & Presets Matrix).
- `eq_studio_preview.png`: Screenshot of Tab 2 (Horizontal Graphic EQ Studio).
- `firmware_preview.png`: Screenshot of Tab 3 (Firmware Diagnostics & Flasher).
- `doctor_preview.png`: Screenshot of Tab 4 or terminal `./audezeforlinux doctor`.
- `backups_preview.png`: Screenshot of Backup snapshots / JSON export.

You can either:
1. Save local `.png` / `.webp` / `.gif` files into this directory (`docs/assets/<filename>.png`).
2. Or drag-and-drop the image into a GitHub issue / release on github.com, copy the `https://github.com/user-attachments/assets/...` URL, and paste it directly into `README.md`.
